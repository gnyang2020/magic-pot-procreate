사용하기 전에 꼭 확인하세요
🟡 카카오 일반 · PSD → PNG · 텍스트만 테두리
• PSD 1개에 이모티콘을 넣어 작업하세요.
• 이모티콘마다 폴더로 분류 (1개만 그려도 폴더로!)
• 폴더 이름은 자유 — 결과는 자동으로 01 02 03… (이름을 01 02 03으로 하면 그 순서대로 나옴)
• 각 폴더 맨 위 레이어 = 텍스트 → 그 텍스트에만 흰 테두리
• 텍스트 없는 이모티콘은 맨 위에 빈 레이어
• 가이드·배경 등 필요 없는 레이어는 눈 끄거나 삭제
📂 예시 (폴더 펼친 모습)
📂 01
  ├ 글씨 레이어 ← 맨 위 (텍스트)
  ├ 캐릭터
  └ 채색
📂 02
  ├ (빈 레이어) ← 텍스트 없을 때
  ├ 캐릭터
  └ 채색
✕ 가이드·배경 → 눈 끄거나 삭제
🟢 카카오 원스톱 · PNG로 나눠 올리기
• PSD 말고 PNG로 뽑아서 올리기
• 텍스트(위) / 캐릭터 / 텍스트(아래)를 각각 PNG로 분리
• 캐릭터 PNG 필수 · 텍스트(아래)는 없으면 생략 가능
• 테두리는 텍스트 PNG에만 (캐릭터엔 X)
• 그림+글자 전체에 테두리 원하면 → 합친 PNG 1장을 텍스트 위·캐릭터 두 칸에 똑같이 넣기
• 가이드는 반드시 삭제하고 PNG로 저장
🖼 분리 예시
🖼 텍스트 (위) ← 테두리 O
🖼 캐릭터 ← 필수 · 테두리 X
🖼 텍스트 (아래) ← 테두리 O · 없으면 생략
🟠 오지큐 멈티 · PSD·PNG → 740×640 · 전체 테두리
• PSD를 넣으면 740×640으로 자동 변환 · 시안 전체에 흰 테두리
• 카카오용으로 그린 PSD(360·1080)도 자동 리사이징 → 740×640으로 출력
• PNG를 넣어도 740×640으로 변환되고 시안 전체에 테두리 적용
• 이모티콘 여러 개 → 각각 폴더로 묶고 폴더 이름 숫자로 시작 (1, 2 / 01, 02)
• 이모티콘 1개 → 그냥 넣기 (숫자 필요 없음)
• 가이드·배경 등 필요 없는 레이어는 눈 끄거나 삭제

🟣 오지큐 움티 · PSD → GIF
• PSD 넣으면 GIF로 자동 출력 (PSD 1개 = 움직이는 이모티콘 1개)
• 각 프레임을 폴더로 나눠 넣으면 그 순서대로 재생
• 폴더 이름이 모두 숫자로 시작(1, 2 / 01, 02 등)이면 숫자 순으로 자동 정렬 · 그 외엔 PSD 레이어 순서
• 프크 PSD의 맨 아래 배경 레이어는 자동 제외 (폴더 밖이면 무조건)
• 순서 직접 지정은 프레임 시퀀스(예: 122331)
• 테두리는 시안 전체에 적용 (텍스트·빈 레이어 규칙 없음)
• GIF는 눈을 꺼도 다 출력돼요 → 가이드는 꼭 삭제!
